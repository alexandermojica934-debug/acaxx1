# Evolving Master Workflow

This document details the integrated procedures for the "evolving" skill, combining the strengths of its source skills into unified, high-stakes workflows.

## Workflow 1: From "Divine Idea" to Market Launch

Use this workflow when the user provides a new business concept or product idea.

### Phase 1: Strategic Synthesis (Soul + Acaso + Stock)
1.  **Omni-Observation**: Gather all "air, noise, and stories" around the idea.
2.  **Council of Weavers**: Run the `acaso-strategic-engine` to generate a report.
3.  **Competitor Deep-Dive**: Call `stock-analysis` APIs for any public companies in the target sector.
4.  **The "Perfect Next" Prediction**: Synthesize into a single strategic roadmap.
5.  **STOP**: Present the roadmap and get user approval.

### Phase 2: Structural Grounding (Business Launch + Excel)
1.  **Legal & Ops**: Identify the entity structure and software stack (Phase 2 of `business-launch-engine`).
2.  **Financial Blueprint**: Create an `excel-generator` workbook with "Overview", "Financial Model", and "KPI Tracking" sheets.
3.  **STOP**: Present the structural plan and Excel model for approval.

### Phase 3: Asset Creation (Frontend + Video)
1.  **Brand Identity**: Define the visual style using `frontend-design` (Bold, non-generic).
2.  **Digital Build**: Initialize a `web-db-user` project if a platform is needed, applying `vercel-react-best-practices`.
3.  **Cinematic Marketing**: Plan a professional video using the `video-generator` Phase 1-3.
4.  **STOP**: Present UI mockups and the video storyboard for approval.

### Phase 4: Launch & Outreach (Lead Gen + API)
1.  **Lead Scraping**: Run `lead-generation-engine` Phase 1-2 to find early adopters.
2.  **Outreach Review**: Present personalized messages to the user.
3.  **API Integration**: If requested, set up `manus-api` webhooks for automated lead processing.
4.  **GO-LIVE**: Execute the launch and outreach.

## Workflow 2: Performance Scaling (Acaso + React + API)

Use this workflow for existing businesses or platforms that need to "evolve" to the next level.

1.  **Weak Signal Scanning**: Use `acaso-strategic-engine` to identify market shifts.
2.  **Technical Audit**: Review the existing React/Next.js codebase against `vercel-react-best-practices`.
3.  **Process Automation**: Implement `manus-api` tasks to handle repetitive operations (e.g., customer support, data entry).
4.  **Optimization**: Update the "Growth" sheet in the master Excel model.

## Critical Guardrails
- **Conciseness**: Keep all outputs high-signal and low-noise.
- **Tone**: Maintain the "Universal Spirit Embodiment" tone—profound and authoritative.
- **Phase Gating**: Never skip the user approval step between major transitions.
